# ProspectPortal — Product one-pager

**Name:** ProspectPortal  
**Type:** New product  
**Status:** Concept / prototype phase

---

## Value proposition

ProspectPortal is a **bot that creates whole websites** tailored to each client with minimal input: one reference link and three key answers. Output is a full site (structure, content, CSS) that matches the client’s intent and can be refined.

**One line:** From one link + 3 answers to a full, compelling website.

---

## Inputs

| Input | Description |
|-------|-------------|
| **Reference link** | The last (or current) site the client has been working on: WordPress site, current site, or any reference URL. The bot uses it to infer structure, style hints, and content type. |
| **3 key questions** | Short discovery flow that prospects what the client wants from the final product (e.g. goal, audience, must-haves). Stored and used to drive generation. |

---

## Output

- A **generated website**: layout, copy, styling, components.
- Built with **CSS tools** and **compelling models** so the result is consistent, polished, and on-brand where applicable.
- Delivered as a **preview link** and/or **export** (e.g. static HTML/CSS); client can iterate.

---

## Differentiator

- **Minimal friction:** No long briefs—one link and three questions.
- **Reference-aware:** Uses the client’s own (or reference) site to guide structure and style, not a generic template.
- **Full site, not just a page:** Multi-section or multi-page output with coherent CSS and content.
- **Compelling by design:** Explicit design/CSS rules and models to meet a quality bar (responsiveness, accessibility, brand alignment as configured).

---

## Target user

- Agencies or freelancers who need a first draft of a client site fast.
- SMBs or teams that want a professional-looking site without a long discovery process.
- Internal teams that need to spin up landing pages or microsites from a reference and a short brief.

---

## Success (v1)

- Client gets a usable first draft from one link + 3 answers.
- Time to first draft is measured in minutes, not days.
- Output is editable and exportable for further refinement.
