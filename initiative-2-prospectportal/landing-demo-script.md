# ProspectPortal — Landing / demo script

Short narrative for “how it works” for internal or external demo and for a landing page.

---

## Landing copy (short)

**Headline:** From one link + 3 answers to a full website.

**Subhead:** ProspectPortal is a bot that creates a complete, ready-to-use site tailored to your goal and audience. Paste the site you’re working on, answer three quick questions, and get a first draft in minutes—not days.

**How it works (3 steps):**

1. **Paste your link** — Your current site, a WordPress build, or any reference. We use it to match structure and style.
2. **Answer 3 questions** — What’s the goal? Who’s the audience? What must be on the first version? That’s all we need.
3. **Get your site** — A full draft with layout, copy, and CSS. Preview, iterate, or export and ship.

**CTA:** Start your first draft / Request demo / See it in action.

## Talking points (if asked)

- **Who is it for?** Agencies, freelancers, SMBs, or internal teams that need a first draft fast without a long discovery process.
- **What if the reference is WordPress?** We ingest the public front-end (structure and style); we don’t need backend access. Output is static HTML/CSS by default; WordPress import could be a later phase.
- **How good is the copy?** We use models and rules tuned for clarity and goal alignment; it’s first-draft quality so humans can edit. We can add brand voice or guidelines later.
- **Can they edit the result?** Yes—export is standard HTML and CSS. Any dev or tool can edit. We may add a simple in-browser editor in a later version.
