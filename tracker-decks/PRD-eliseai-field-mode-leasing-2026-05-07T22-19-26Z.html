PRD: Field-Mode Leasing — in-property agent app

Drop: 2026-05-07T22-19-26Z · Tier Now · Effort L · Triggered by EliseAI "Agent" launch

Problem

EliseAI's "Agent" is a mobile CRM — office software running on a phone. The actual gap nobody's filled is what a leasing agent does at the property, on the tour, hands full. EliseAI cannot ship this because they don't own the PMS, maintenance, screening, or pricing engines underneath. This is a platform play, not a positioning play.

Target user

Leasing agents during in-person tours (the 15–45 minute window between unlock and lease-decision). Secondary: regional managers reviewing tour outcomes.

Scope (in)

  • In-tour module in the existing Entrata mobile app: photo capture tied to the unit record, voice-to-text tour notes auto-attached to the prospect, prospect-question log.
  • Push-to-apply from the unit door: agent triggers an SMS deep-link to the prospect's phone; the link opens a pre-filled application with live PMS pricing for this exact unit + lease-term combination (not yesterday's snapshot).
  • In-field maintenance ticket creation: agent spots an issue during the tour → 2-tap maintenance ticket pre-populated with unit ID, photo, and location-in-unit (kitchen / bath / etc.).
  • Live conditional-pricing preview: while standing in the unit, agent can show the prospect their screening-conditional offer (e.g., "with a co-signer, your rate is X") pulled from the screening + pricing engines.
  • Offline-first: tour module works without signal in basements/garages; syncs on reconnect.

Scope (out)

  • Redesigning the desktop CRM.
  • Building a separate standalone app — extend the existing Entrata mobile app.
  • Replacing existing screening or pricing engines — only consume them via internal APIs.

Success metric

≥40% of toured units have a Field-Mode session attached within 6 months of launch; tour-to-application rate lifts ≥8% on Field-Mode tours vs. non-Field-Mode control across pilot customers.
